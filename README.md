# We'll Be ― 家族とAIがそばにいる通院支援アプリ（モックアップ）

**近畿大学病院 通院支援アプリ アイデアコンテスト2026**  
チーム **We'll Be** 提案モックアップ

---

## 1. 概要
本リポジトリは、提案「**We'll Be ― 家族とAIがそばにいる通院**」の3つの軸と共通フッターUIを体験できるインタラクティブWebモックアップです。

- **軸1：見守り家族**（招待コードによる来院不要の家族登録・通院進捗／服薬／持ち物のリアルタイム共有・ひとことメッセージ送信）
- **軸2：AI通院コンシェルジュ**（毎日の服薬確認・症状の音声記録・危険キーワード検知による緊急連絡案内・診察前のメモ自動要約＆医師提示用の大文字表示）
- **軸3：おまかせ受付**（前日通知から1タップで当日朝の「どこでも受付」を自動化）
- **共通フッターメニュー**（どの画面からでも1タップで「ホーム」「コンシェルジュ」「見守り家族」へ移動可能）

---

## 2. 使い方・起動方法

ビルド不要（HTML / CSS / Vanilla JS）のため、`index.html` をブラウザでそのまま開くだけで動作します。

### PCで開いた場合
- 画面中央にiPhoneフレーム付きでアプリが表示され、右側に**画面解説＆リアルタイム連動ステータス**が表示されます。
- 上部のコントロールバーから「**患者本人（近大 太郎）** ⇔ **見守り家族（娘・スマホ）**」の視点切替、全画面へのクイックジャンプ、「**↺ デモ初期化**」が行えます。

### スマートフォン実機で開いた場合（画面幅 `600px` 未満）
- スマホフレームが自動で非表示になり、**全画面のネイティブアプリ風表示**に切り替わります。
- ブラウザのメニューから「ホーム画面に追加」を行うと、PWA（スタンドアロン表示）としてアプリのように起動できます。

## 3. デモ実演のおすすめシナリオ（画面間連動）

1. **① ホーム画面**：
   - 診察券の下にある「**AIコンシェルジュに話しかける**」ボタン、または「**服薬サポート**」アイコンをタップ。
2. **②-A 服薬サポート**：
   - 「`飲んだよ。そういえば今朝、ちょっとふらついた。`」のデモ発話ボタンをタップ。
   - 夜のお薬が「✅ 飲んだ」に変わり、今朝の「ふらつき」が **③ 診察前のメモ** と **⑤-B 見守り家族** の服薬状況に自動反映されます。
3. **②-B 症状の記録 ＆ 危険サイン検知**：
   - 上部サブタブ「💬 症状の記録・相談」へ切り替え、ワンタップ発話ボタンやマイクボタンで会話を実演。
   - 「`⚠️ 胸が強く痛んで息苦しい`」を押すと、ルールベース検知が作動し、記録より先に **病院への電話・119番** を促す警告枠がハイライトされます。
4. **③ 診察前のメモ**：
   - 記録された症状と飲み忘れ回数が一覧化されていることを確認し、「**診察で先生に見せる（大きな文字で表示）**」をタップして医師提示用の大文字画面を表示。
5. **⑥ 持ち物チェック ＆ ④ おまかせ受付**：
   - 「カバンに入れた（用意できた）」ボタンや、「明日の受付をしておく」スイッチを操作すると、**⑤-B 見守り家族** 側の画面表示がリアルタイムに連動します。
6. **⑤-A / ⑤-B 見守り家族（家族のスマホ）**：
   - 招待コード `472915` で登録後、親の通院タイムラインを確認。「**ひとことメッセージを送る**」からメッセージを送ると、本人側のホーム画面に通知バナーが届きます。
